The campaign relies on a structured eight-stage GenAI workflow:$$\text{Business Brief} \longrightarrow \text{Prompt Design} \longrightarrow \text{AI Generation} \longrightarrow \text{Human Review} \longrightarrow \text{Source Verification} \longrightarrow \text{Correction} \longrightarrow \text{Human Approval} \longrightarrow \text{Passenger Communication}$$Using tools like ChatGPT for structured copywriting, Canva/Gamma for slide and visual design, document-grounded AI for source verification, and GitHub for open-portfolio documentation, the workflow establishes explicit boundaries. Crucially, the AI is constrained from inventing specific baggage allowances, security regulations, or queue time guarantees—focusing exclusively on directing passengers toward official, verified airline and airport channels.Quality Control, Audit & VerificationTo maintain aviation-grade compliance, every generated artifact—including the awareness email, social media posts, and terminal poster concept—underwent a Four-Dimension Review (Accuracy, Tone, Compliance, and Context) alongside rigorous audits:Hallucination & Severity Triage: Unsupported statements (e.g., guaranteed on-time departures or specific bag limits) were tagged as [VERIFY] and systematically removed or replaced with generic guidance. High-risk operational claims were restricted until checked against official sources.Privacy & Data Protection: Strict data minimization principles ensured zero real passenger names, booking references, or passport details entered public AI models or the public GitHub repository (genai-business-portfolio/day-14-capstone-portfolio).Verification Trail: Each retained claim was validated using a strict $Claim \rightarrow Source \rightarrow Match \rightarrow Context \rightarrow Action$ pipeline, ensuring no AI output was accepted as automatically factual.Key TakeawayWhile Generative AI accelerates content drafting and layout organization, human judgment remains indispensable in aviation management to safeguard operational accuracy, maintain passenger trust, and uphold regulatory compliance.
